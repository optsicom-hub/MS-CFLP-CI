The results reported in the paper were obtained with the following command:
Project2.exe "nameinstXX.txt" --pct_open 0.6964 --subproblem_size 25 --strategy 2 --divisor_time 2

The total time limit is set in main.cpp through the variable tmax. It can be used as is (original time limits) or multiplied by ratio_PASS, the ratio between the PassMark CPU benchmark scores of the two machines, to adjust it to the speed of the machine used.
